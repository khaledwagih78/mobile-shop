# الموقع العام للعملاء (قائمة الأسعار)

صفحة واحدة (`index.html`) يفتحها العميل فيشوف **اسم المنتج + سعر البيع** بس.
بتقرا مباشرة من فاترينة `public_catalog` الآمنة في Supabase — فمفيش أي تكلفة
أو أرباح أو عملاء بيوصلوا للصفحة دي أبداً.

## قبل ما تبدأ
لازم تكون نفّذت إعداد الأمان الأول (مرة واحدة لكل محل):
راجع [`../docs/public-storefront-ar.md`](../docs/public-storefront-ar.md)
(تشغيل `schema.sql` + حساب المالك + `.env`).

## خطوات التشغيل

### 1) ظبط بيانات محلك
افتح `storefront/index.html` وعدّل البلوك اللي في أوله:
```js
const CFG = {
  SHOP_NAME: 'اسم محلك',
  TAGLINE:   'الأسعار المتوفرة حالياً',
  CURRENCY:  'ج.م',
  SUPABASE_URL:      'https://xxxx.supabase.co',   // نفس مشروع البرنامج
  SUPABASE_ANON_KEY: 'eyJhbGci...',                // مفتاح anon (آمن للنشر)
};
```
> مفتاح anon آمن تحطه هنا — لأنه بعد قفل الصلاحيات مايقدرش يقرا غير الفاترينة.

### 2) علّم على الأصناف اللي تظهر
في البرنامج → **المخزون** → افتح الصنف → علّم **"يظهر في موقع العملاء"**.
الأصناف دي بس هي اللي هتبان في الموقع (وبسعر البيع).

### 3) انشر الصفحة
اختار أي طريقة:

**أ) Netlify Drop (الأسهل):** افتح https://app.netlify.com/drop واسحب
مجلد `storefront` كله. هياخد لينك على طول.

**ب) GitHub Pages:** ارفع المجلد، وفعّل Pages على الفرع، والصفحة تبقى على
`https://<user>.github.io/<repo>/storefront/`.

**ج) أي استضافة:** ارفع `index.html` زي ما هو — مفيش build ولا سيرفر مطلوب.

### 4) وزّع اللينك
ابعت اللينك للعملاء (واتساب / البايو / كارت المحل). يفتح على الموبايل والكمبيوتر.

## ملاحظات
- لو بيانات Supabase مش متظبّطة، الصفحة بتشتغل **وضع تجريبي** ببيانات نموذجية
  عشان تشوف الشكل.
- الأسعار بتتحدّث تلقائياً كل ما البرنامج يزامن (أول ما يكون فيه نت).
- عايز تزوّد صور / بحث متقدم / دخول عملاء للجملة؟ ده المرحلة الجاية.
