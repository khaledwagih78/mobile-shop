# قفل الصلاحيات + فاترينة الموقع العام — دليل الإعداد

الهدف: الموقع العام للعميل يشوف **اسم الصنف + سعر البيع فقط**. لا تكلفة، لا أرباح،
لا عملاء، لا فواتير. أي حد غير برنامج صاحب المحل لا يقدر يقرأ أي بيانات حسّاسة.

> ⚠️ مهم: بعد هذا الإعداد، البرنامج **لازم يسجّل دخول للسحابة** عشان المزامنة تشتغل.
> ده السطر اللي بيخلّي البرنامج يشوف كل حاجة والموقع يشوف الفاترينة بس.

---

## نظرة سريعة على اللي اتعمل

| الطبقة | مين يقراها | فيها إيه |
|---|---|---|
| `public_catalog` (فاترينة) | أي زائر للموقع (anon) | اسم + سعر بيع + ماركة + نوع + كود + باركود |
| الجداول الحقيقية (أصناف، عملاء، فواتير…) | برنامج المحل بعد تسجيل الدخول فقط | كل حاجة |

- الأصناف اللي بتظهر في الفاترينة هي **اللي معلّم عليها "يظهر في موقع العملاء"** في
  شاشة المخزون + سعر البيع أكبر من صفر.
- كل محل له مشروع Supabase خاص (من `.env`)، فمفيش خلط بيانات بين المحلات.

---

## خطوات التفعيل (لكل محل — مرة واحدة)

### 1) شغّل ملف الـ SQL
افتح Supabase → **SQL Editor** → **New Query** → الصق محتوى `supabase/schema.sql`
→ **Run**. ده بيقفل كل الجداول للمستخدم المسجّل، وبيعمل فاترينة `public_catalog`.

### 2) اعمل حساب صاحب المحل (مرة واحدة)
في Supabase → **Authentication → Users → Add user**:
- اكتب إيميل + باسورد (أي إيميل، مش لازم حقيقي)
- علّم على **Auto Confirm User**
- **Create**

### 3) حط البيانات في ملف `.env` بتاع البرنامج
```
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGci...
VITE_SUPABASE_OWNER_EMAIL=owner@theshop.example
VITE_SUPABASE_OWNER_PASSWORD=الباسورد-اللي-كتبته
```

### 4) أعد بناء البرنامج
```
npm run build        # أو npm run electron:build لنسخة الديسكتوب
```
البرنامج دلوقتي هيسجّل دخول للسحابة تلقائياً قبل كل مزامنة.

### 5) علّم على الأصناف اللي عايزها تظهر
في شاشة **المخزون** → افتح الصنف → علّم **"يظهر في موقع العملاء (بسعر البيع فقط)"**.
الافتراضي إن مفيش حاجة تظهر — لازم تعلّم يدوياً (أأمن).

---

## إزاي الموقع العام يقرأ الفاترينة

الموقع (أو أي صفحة بسيطة) بيستخدم **مفتاح anon** ويقرا من الـ view بس:

```js
import { createClient } from '@supabase/supabase-js';
const sb = createClient(SUPABASE_URL, SUPABASE_ANON_KEY);

const { data, error } = await sb
  .from('public_catalog')
  .select('name, price, brand, category')
  .order('name');
// data = [{ name, price, brand, category }, ...]
```

لو حد حاول يقرا الجداول الحقيقية بنفس المفتاح:
```js
await sb.from('items').select('*');     // => [] (مفيش صلاحية — صفر صفوف)
await sb.from('customers').select('*'); // => [] برضه
```

---

## ملاحظات أمان

- مفتاح الـ anon ممكن يتحط في الموقع العام بأمان — لأنه دلوقتي **مايقدرش يقرا غير
  الفاترينة**.
- بيانات التكلفة والأرباح والعملاء محبوسة تماماً خلف تسجيل دخول صاحب المحل.
- لو عايز تلغي الفاترينة مؤقتاً: `DROP VIEW public.public_catalog;` في SQL Editor.
- لو عايز ترجع للوضع القديم المفتوح (بدون موقع عام): سيب `VITE_SUPABASE_OWNER_*`
  فاضية — البرنامج هيزامن بالطريقة القديمة (بس ساعتها البيانات مش محمية).
